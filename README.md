# 🤖 Proxy Hunter Bot

بات شکارچی پروکسی MTProto تلگرام — ۲۴ ساعته روی GitHub Actions، با کنترل کامل از داخل تلگرام.

## ✨ امکانات

- 🔍 **اسکن خودکار کل اینترنت** برای پروکسی‌های MTProto که در ایران کار می‌کنند
- 🔁 **ران خودکار بی‌نهایت**: قبل از اتمام هر Run، خودش با سکرت `GH_PAT` ران جدید می‌زند
- 💾 **ذخیره مداوم دیتا** در دیتابیس SQLite لوکال + کامیت به ریپو + Artifact — بین ران‌ها **هیچی گم نمی‌شه**
- ⚡ **پایپ‌لاین ۵ مرحله‌ای**:
  1. جمع‌آوری از ده‌ها منبع (لیست‌های GitHub، کانال‌های تلگرام، APIها + منابع کشف‌شده توسط AI)
  2. حذف تکراری‌ها
  3. تست پینگ (TCP latency)
  4. تست دانلود/آپلود
  5. فیلتر نهایی با امتیاز ترکیبی (پینگ ۶۰٪ + سرعت ۴۰٪)
- 🎛 **کنترل کامل از تلگرام**: دکمه‌های شیشه‌ای (Inline)، کیبورد معمولی، و لیست کامندها
- 🌍 **حالت عمومی/خصوصی** — در حالت عمومی همه می‌تونن استارت بزنن ولی کارهای حساس فقط برای ادمین
- 👑 **مدیریت ادمین** — افزودن/حذف ادمین با سطح دسترسی (owner / admin / viewer)
- 🌐 **۱۰ زبان** (پیش‌فرض انگلیسی، فارسی دومین گزینه)
- 📜 **لاگ زنده** — مرحله فعلی، تعداد پروکسی‌ها، وضعیت دیتابیس
- 📄 ارسال لیست پروکسی به صورت **فایل** یا **متن**، با تعداد قابل تنظیم
- 🧵 تنظیم **تعداد ترید**، **فاصله اسکن**، **اندازه دسته** از داخل بات

## 🧠 Proxy AI

ایجنت داخلی پروژه با معماری الهام‌گرفته از **Hermes Agent** (Nous Research):

- **راه‌اندازی اولیه**: اولین بار `base_url` و `API key` هر provider سازگار با OpenAI رو می‌گیره، لیست مدل‌ها رو میاره و انتخاب می‌کنی
- **حافظه دائمی**: می‌تونی بهش بگی «منو داداش صدا کن» — توی مموری ذخیره می‌شه و بهت اطلاع می‌ده چی ذخیره شد
- **یادگیری اسکیل**: رویه‌ها رو به صورت فایل Markdown یاد می‌گیره و دفعات بعد استفاده می‌کنه
- **کشف منابع جدید**: با سرچ **Tavily** (سکرت `TAVILY_API_KEY`) منابع تازه پروکسی پیدا و به لیست اضافه می‌کنه
- **شناخت کامل پروژه**: نقشه معماری (کدوم فایل کجاست، چی کار می‌کنه) توی سیستم پرامپتش هست
- **اجازه برای کارهای حساس**: قبل از تغییر فایل/تنظیمات/حذف دیتا، ازت تأیید می‌گیره (دکمه Approve/Deny)
- **رفع باگ**: باگ رو گزارش بده → سرچ می‌کنه → فیکس پیشنهاد می‌ده → بعد از تأیید اعمال می‌کنه

## 🚀 راه‌اندازی

1. ریپو رو بساز و این کد رو پوش کن (برنچ `main`)
2. توی **Settings → Secrets and variables → Actions** این سکرت‌ها رو اضافه کن:

| Secret | توضیح |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن بات از @BotFather |
| `ADMIN_ID` | آیدی عددی تلگرام خودت (ادمین اول) |
| `GH_PAT` | Personal Access Token با اسکوپ `repo` + `workflow` |
| `TAVILY_API_KEY` | کلید سرچ Tavily (برای Proxy AI) |

3. برو به **Actions → 🤖 Telegram Proxy Hunter Bot → Run workflow**
4. از این به بعد بات خودش قبل از پایان هر ران، ران بعدی رو فعال می‌کنه 🔁

## 📁 ساختار پروژه

```
bot/main.py            → نقطه شروع (بات + scheduler + autosave)
bot/config.py          → تنظیمات و متغیرهای محیطی
bot/database.py        → دیتابیس SQLite (همه جداول)
bot/scraper/           → مرحله ۱و۲: جمع‌آوری + dedupe
bot/tester/            → مرحله ۳-۵: پینگ، سرعت، فیلتر
bot/telegram_bot/      → هندلرها و کیبوردها
bot/ai/agent.py        → Proxy AI (حافظه، اسکیل، Tavily، تأیید اقدامات حساس)
bot/scheduler.py       → حلقه اسکن + ذخیره دوره‌ای
data/proxybot.sqlite3  → دیتابیس (کامیت می‌شه، ماندگار)
.github/workflows/     → ورک‌فلوی اجرا + ری‌استارت خودکار
```

## ⚠️ نکات

- محدودیت هر ران GitHub Actions ≈ ۶ ساعته؛ بات خودش زنجیره‌ای ادامه می‌ده
- رانر GitHub خارج از ایران است؛ پروکسی‌هایی که از رانر تست می‌شن و جواب می‌دن، معمولاً داخل ایران هم کار می‌کنن
- هر ۶۰ ثانیه دیتابیس کامیت می‌شه؛ تست‌های لحظه‌ای هم بلافاصله توی DB ذخیره می‌شن
